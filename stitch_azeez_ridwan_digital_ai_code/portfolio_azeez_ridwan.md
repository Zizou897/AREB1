# 2. Stack technique

Le portfolio sera développé avec une stack volontairement cohérente, légère et performante :

- **Django** — backend, administration, gestion des données
- **HTMX** — interactions dynamiques sans frontend lourd
- **TailwindCSS** — interface moderne et responsive
- **MySQL** — base de données
- HTML5 / CSS3
- JavaScript lorsque nécessaire

### Philosophie technique

Le projet doit démontrer qu'une expérience web moderne peut être construite avec Django + HTMX + Tailwind sans dépendre nécessairement d'un framework frontend lourd.

HTMX pourra être utilisé pour :

- Filtrer les projets sans rechargement complet
- Charger les détails d'un projet
- Ouvrir des modales
- Charger progressivement les contenus
- Gérer le formulaire de contact
- Pagination dynamique
- Navigation partielle
- Transitions entre contenus
- Chargement différé des vidéos et images

# 17. Modèle Django — Project

Exemple de modèle :

```python
class Project(models.Model):
    title = models.CharField(max_length=200)
    slug = models.SlugField(unique=True)
    category = models.CharField(max_length=100)
    description = models.TextField()
    cover = models.ImageField(upload_to="projects/")
    technologies = models.JSONField(default=list)
    featured = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)
```

Le modèle pourra ensuite évoluer avec :

- Client
- Année
- URL
- GitHub
- Galerie
- Challenge
- Solution
- Résultats
- Featured image
- Ordre d'affichage
- Statut publié/brouillon

class VideoProject(models.Model):

# 19. Django Admin

L'ensemble du portfolio doit être administrable depuis Django Admin.

Exemples :

**Projects → Add Project**

**AI Videos → Add Video**

**Services → Add Service**

**Messages → View Messages**

Cela permet d'ajouter un nouveau projet sans modifier le code du frontend.

### Exemple de workflow

1. Réalisation d'un nouveau projet
2. Préparation des screenshots
3. Ajout dans Django Admin
4. Sélection de la catégorie
5. Ajout des technologies
6. Ajout de la description
7. Activation de « Featured »
8. Publication

Le portfolio se met ensuite automatiquement à jour.
